# racelineV5 最小曲率候选：离线报告

状态：`offline_candidate_not_deployed`。该候选只替换赛道几何；stableV3 的控制器、车辆参数、H3/0.30 残差模型和 racelineV3 均未改动。

## 设计范围

四个相邻弯作为一个连续弯组联合优化，而不是在单个 s 点打补丁：

- C1：原线 s=14.0–24.5 m，关注点 18.25 m
- C2：原线 s=26.0–32.0 m，关注点 28.75 m
- C3：原线 s=34.0–41.5 m，关注点 36.25 m
- C4：原线 s=43.0–51.5 m，关注点 44.75 m

候选沿 racelineV3 法向最多移动 0.20 m，通过交替使用入弯外侧、弯心和出弯外侧来增大转弯半径。优化目标以曲率峰值、曲率变化率和平滑性为主，整圈时间只作弱约束。

## 结果

| 区域 | 峰值曲率 V3 → V5 (1/m) | 降幅 | 最小半径 V3 → V5 (m) | 区域最低规划速度 V3 → V5 (m/s) |
|---|---:|---:|---:|---:|
| C1 | 1.105 → 0.836 | 24.3% | 0.905 → 1.196 | 1.700 → 1.947 |
| C2 | 1.379 → 1.086 | 21.3% | 0.725 → 0.921 | 1.523 → 1.703 |
| C3 | 0.992 → 0.795 | 19.8% | 1.008 → 1.257 | 1.796 → 1.995 |
| C4 | 1.341 → 1.067 | 20.4% | 0.746 → 0.937 | 1.544 → 1.724 |

四区峰值转弯半径提高约 25%–32%，局部最低速度提高约 0.18–0.25 m/s。优化器正常收敛，最终 objective 为 1.018986。

代价是路径变长：87.760 → 89.681 m（+1.921 m）。仅按静态 stableV3 速度包络积分，估算圈时 32.447 → 32.668 s，即慢 0.221 s。因此它是“更平滑、更容易真实跟踪”的候选，不是离线计算已经证明更快的候选；真实收益必须通过闭环 bag 判断。
